# CSS Learning Repository

This repository contains my CSS practice codes and examples created while learning CSS from the basics.

## About

I am learning CSS to understand how webpages are styled and how different styling properties are used to improve the appearance and layout of HTML elements.

This repository includes small and large code examples covering the CSS concepts I have learned and practised.

## Topics Covered

- Introduction to CSS
- Types of CSS (Inline, Internal and External)
- CSS Syntax
- Selectors
- Element, Class and ID Selectors
- Colors and Backgrounds
- Text Styling
- Font Properties
- Borders
- Margins and Padding
- Width and Height
- Box Model
- Display Property
- Flexbox
- CSS Positioning
- Styling HTML Forms and Buttons
- Styling Div and Other HTML Elements

## Language Used

- CSS3

## Goal

- Learn CSS fundamentals.
- Practise different CSS properties and selectors.
- Understand webpage styling and layout.
- Improve the appearance of HTML pages.
- Build a strong foundation for frontend development.

This repository is part of my ongoing web development learning journey.
